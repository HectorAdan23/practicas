Practica 4: gestorEstudiantes.c

1) ¿Que hace?
Con datos de 3 estudiantes que ingrese el usuario, comparará el mejor promedio y lo imprimira. Este programa usa estructura para
capturar cada dato del estudiante.

2) ¿Problemas?
No guarda nada una vez se cierra el propio programa, solo sirve en la ejecucion, pues los datos se eliminaran al cerrar
la terminal

3) ¿En ejecucion?
La parte principal del programa (hallar el promedio con mejor puntaje) solo se ejecutara al terminar de ingresar los datos de los
3 estudiantes que acepta el programa y luego se termina el programa.

Alguna duda, aclaracion u otra, favor de ser estrictamente claros con las opiniones.
